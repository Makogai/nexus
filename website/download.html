NEXUS v0.1.0

Download NEXUS

Free for Windows, macOS and Linux. Installs for your user only — no administrator rights — and keeps your data separate from the program.

Windows

Your system

Windows 10 and 11 (x64). Per-user installer; programs in %LOCALAPPDATA%\Programs\NEXUS, data in %LOCALAPPDATA%\NEXUS.

Installer .exe

macOS

Your system

macOS 11 or later. Open the disk image and drag NEXUS to Applications.

Apple silicon .dmg Intel .dmg

Linux

Your system

x64. The AppImage runs on most distributions; the Debian package suits Ubuntu, Debian and derivatives.

AppImage Debian package .deb

Before you start

  • Claude Code installed and signed in — NEXUS launches it; it does not replace it.
  • Git for repository features and workspace sync.
  • Optional: Graphify for a code knowledge graph when you learn a project.

First start — the builds are not code-signed yet

  • Windows: SmartScreen shows “Windows protected your PC” → More info → Run anyway.
  • macOS: ad-hoc signed, not notarized → right-click NEXUS → Open once (or System Settings → Privacy & Security → Open Anyway).
  • Linux: chmod +x NEXUS_*.AppImage, then run it — or sudo apt install ./NEXUS_*.deb.

Verify your download

Every release lists SHA-256 checksums in SHA256SUMS.txt and carries a build-provenance attestation:

gh attestation verify <file> --repo Makogai/nexus

Updating

Install the new version over the old one — your workspaces, sessions and settings stay where they are, and NEXUS backs up its data before an upgrade. Release notes for every version are on GitHub Releases.
